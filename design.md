# Orbit design system

Source: image

## Character

Orbit usa uma interface desktop escura, técnica e premium. A composição é arejada, com superfícies discretas, bordas finas, alto contraste e acento roxo azulado. A sidebar é permanente em telas largas. O conteúdo usa hierarquia clara e ilustrações construídas a partir da linguagem visual do Canvas.

## Build mandate

As telas devem usar tokens definidos em `src/App.css`. Ações principais usam o acento roxo. Estados semânticos usam cores específicas apenas como suporte. Evite fundos claros, sombras pesadas, bordas em excesso e tipografia manuscrita fora de anotações do Canvas.

## Responsive behavior

Em larguras médias, a sidebar reduz para ícones e os grids reduzem suas colunas. Em larguras pequenas, a barra lateral torna se uma barra compacta superior, o hero fica em coluna e os grids ficam com uma coluna. A animação é reduzida quando o sistema solicitar menos movimento.
